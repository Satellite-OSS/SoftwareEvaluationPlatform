# Original Evaluation Tools

## Basic Info
This directory contains the **original evaluation tools developed by OPENSAT**. These tools are designed to assess various aspects of software performance and compatibility across different environments. The tools will be formatted into the categories below, which are closely **related to the research conducted by members of OPENSAT**:

- Containerized Software Evaluation
- Wasm(WebAssembly) Software Evaluation
- ...
